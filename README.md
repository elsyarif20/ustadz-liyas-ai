# 👳‍♂️ Ustadz Liyas Syarifudin AI

Aplikasi AI interaktif yang berperan sebagai sosok bijak, menghibur, dan memotivasi. Dibuat menggunakan **Streamlit** dan **Google Gemini 3 Flash**.

## ✨ Fitur Utama
*   **Analisis Aura & Karakter:** Kirim foto dan nama lengkapmu, Ustadz akan menganalisis karaktermu secara positif.
*   **Teman Curhat:** Bisa diajak diskusi masalah kehidupan dengan jawaban yang tidak *lebay* tapi tetap bijak.
*   **Teknologi Terbaru:** Menggunakan SDK `google-genai` dengan metode File API untuk pemrosesan gambar yang cepat.
